# QuestPop

QuestPop is a frictionless productivity web app that turns overwhelming goals into tiny, actionable quests.

## Features

- Goal-to-quest generation
- Energy level selection
- Focus timer
- Progress tracking
- Persistent quest history
- Stats
- Responsive comic-style UI
- No signup required

## Tech Stack

React, Vite, JavaScript, CSS, LocalStorage

## Run Locally

npm install
npm run dev

## Build

npm run build
